# 压力之纪：二〇一〇—二〇三五年批判性宏观史

十二篇，写 2010 到 2035 年教育压力、家庭控制、青少年心理危机、游戏治理、封闭矫正产业与平台社会怎么互相咬合。每篇标出证据等级：哪些核过原文，哪些是推断，哪些查不到公开数据。

## 读法

白话版十二章，打开就是目录与正文：

1. 这十五年，政策一年比一年密
2. 学校把分数变成了唯一通行证
3. 家长为什么不肯松手
4. 孩子是怎样垮下来的
5. 游戏为什么成了替罪羊
6. 把“不听话”当成病来治
7. 平台和 AI 成了新的看门人
8. 谁在靠焦虑赚钱
9. 三十一种人的处境
10. 为什么改不动
11. 2035 年之前，可能有哪几种走向
12. 我掌握了哪些证据，哪些没有

## 证据怎么标

| 情况 | 写法 |
|---|---|
| 核对过原始文件 | 我核过原文 |
| 从材料推出，原文没直接写 | 我推断、很可能 |
| 对 2035 年前的判断 | 这是预测 |
| 查不到公开数据 | 我没有查到公开数据、这一点存疑 |

旧版保留 `实·甲`、`实·乙`、`推`、`测`、`阙` 五级标签，供复核。

## 写作纪律

- 不编资料、事件、数据、论文、法律与引语。
- 法律与文件只写名称、发布主体、时间与可核条款。
- 列传写类型，不给真实个体编生平、对话与心理。
- 证据不足就标注，不用精确数字撑论证。
