# 压力之纪：二〇一〇—二〇三五年批判性宏观史

一部以可核验证据写成的当代史，围绕教育压力、家庭控制、青少年心理危机、游戏治理、封闭矫正产业、AI 与平台社会，解释这段时间如何形成。

## 体例

白话版共十二章，打开就是目录和正文：

1. 这十五年，政策一年比一年密
2. 学校把分数变成了唯一通行证
3. 家长为什么不肯松手
4. 孩子是怎样垮下来的
5. 游戏为什么成了替罪羊
6. 把“不听话”当成病来治
7. 平台和 AI 成了新的看门人
8. 谁在靠焦虑赚钱
9. 三十一种人的处境
10. 为什么改不动
11. 2035 年之前，可能有哪几种走向
12. 我掌握了哪些证据，哪些没有

## 证据处理

白话版不再使用符号标签，改用白话说明：能核对的写“我核过原文”，推断写“我推断”“很可能”，预测写“这是预测”，查不到的写“我没有查到公开数据”或“这一点存疑”。旧版保留 `实·甲`、`实·乙`、`推`、`测`、`阙` 五级标签，供复核。
