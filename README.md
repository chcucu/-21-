# 压力之纪：二〇一〇—二〇三五年批判性宏观史

一部以可核验证据写成的当代史，围绕教育压力、家庭控制、青少年心理危机、游戏治理、封闭矫正产业、AI 与平台社会，解释这段时间如何形成。

## 体例

- 本纪二：教改与「双减」、网络与游戏治理
- 表四：制度年表、数据口径、政策工具、制度接触点
- 书六：教育压力、家庭控制、心理危机、游戏治理、矫正产业、AI 与平台
- 世家一：利益链
- 列传三十一：失声群体（类型列传，非特定个人）
- 综论：因果链、责任分层、反事实与反例
- 预测：二〇二七—二〇三五条件式情景，附反证信号
- 卷末：证据清单、存疑表、方法与限度

## 证据分级

正文以标签区分：`实·甲`（已复核原文）、`实·乙`（公认事实）、`推`（推断）、`测`（预测）、`阙`（证据不足）。二〇二五年以后一律为条件式情景，不作事实断言。

- 不编造资料、事件、数据、论文、法律与引语
